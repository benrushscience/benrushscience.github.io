# Map iframe pages

This folder hosts the standalone HTML pages that can replace large Squarespace code blocks with iframes.

## Published routes

- `https://benrushscience.github.io/map/improv-group-map/`
- `https://benrushscience.github.io/map/improv-group-table/`
- `https://benrushscience.github.io/map/improv-festival-map/`
- `https://benrushscience.github.io/map/improv-festival-table/`

## Squarespace iframe snippets

Paste the relevant snippet into a Squarespace Code block.

### Improv Group Map

```html
<iframe
  src="https://benrushscience.github.io/map/improv-group-map/"
  title="Improv Group Map"
  style="width:100%;height:760px;border:0;display:block;"
  loading="lazy"
  allow="geolocation; fullscreen"
  allowfullscreen>
</iframe>
```
